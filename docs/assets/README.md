# Исходники вёрстки и рисунки

Каталог держит то, из чего собран отчёт docs/reports/report_2026_08_13_tokens_RU.md:
исходник вёрстки, его сборку, рисунки и библиографию.

Сборка идёт из того, что лежит рядом, без обращения к другим каталогам:

```
cd docs/assets
pdflatex report_2026_08_13_tokens_RU
bibtex   report_2026_08_13_tokens_RU
pdflatex report_2026_08_13_tokens_RU
pdflatex report_2026_08_13_tokens_RU
```

Что здесь лежит:

- report_2026_08_13_tokens_RU.tex — исходник вёрстки, ревизия 7b9259e проекта
  Overleaf. Файл побайтово равен той ревизии, поэтому его не правят: любая
  правка рвёт сверку происхождения по хэшу. Введение отчёта в markdown с тех
  пор переписано, и исходник этой правки не содержит: он отвечает состоянию до
  неё. По той же причине пересборка из этого каталога больше не повторяет
  отчёт дословно: вёрстка подхватит новый рисунок на четыре единицы, а подпись
  и текст в ней останутся прежние, на три.
- report_2026_08_13_tokens_RU.pdf — сборка этого исходника, хранится через
  git lfs.
- references.bib — библиография, оттуда же.
- acl_natbib.bst — стиль библиографии. Копия лежит здесь, чтобы сборка
  не зависела от соседних каталогов.
- fig_levels.png и fig_levels.pdf — рисунок 1 отчёта, четыре единицы описания
  трассы: поток токенов, типизированные события, интервалы, циклы рассуждений.
  Рисунок перерисован 17 августа 2026 года вместе с правкой введения; прежняя
  версия на три единицы осталась в истории git.
- draw_fig_levels.py — код, которым нарисован рисунок 1. Запуск перезаписывает
  fig_levels.png и fig_levels.pdf рядом со скриптом.
- fig_pareto.pdf — рисунок 2 отчёта в векторном виде, его берёт вёрстка.
- fig_pareto.png — тот же рисунок в растре, его берёт разметка md: вёрстка
  показывает pdf, а страница на вебе его не покажет.

Рисунки прежней редакции отчёта убраны: статья сняла приложения, в которых они
стояли, и ссылок на них не осталось. Они лежат в истории git.
