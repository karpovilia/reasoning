# Зависимости

Дата: 2026-10-02

Рабочие версии для детектора и гейта зафиксированы в [pyproject.toml](../../pyproject.toml): Python 3.10–3.12, NumPy 1.26.4, SciPy 1.14.1, scikit-learn 1.6.1, PyTorch 2.9.1. Проверки выпуска выполнены на Python 3.12.13. Выбор версий соответствует окружению, в котором загружены и проверены существующие веса.

Детектор использует NumPy, SciPy и scikit-learn. Гейт использует NumPy и PyTorch, а калибровка времени — SciPy. Для инференса этих моделей достаточно CPU. Версия scikit-learn особенно существенна для загрузки сохранённого pickle. Загружайте pickle и PyTorch-чекпоинты только из доверенного выпуска и сверяйте их SHA-256.

Дополнительные группы установки:

- `.[data]`: JSON Schema и Zstandard для работы с будущими архивами;
- `.[tokenization]`: tokenizers 0.22.2 для работы с сохранённым токенизатором решателя;
- `.[test]`: pytest, если нужен этот раннер. Сами тесты запускаются стандартным `unittest` и не требуют pytest.

Git LFS нужен для скачивания весов. `make check` использует Python стандартной библиотеки; полная проверка отсутствия утечек HLE дополнительно читает локальный эталон через pyarrow. В проверенном рабочем окружении pyarrow 18.1.0.

## Окружение большого разметчика

Обучение LoRA требует GPU и отдельного окружения с PyTorch, Transformers, PEFT и Accelerate; слияние весов также использует safetensors. Сохранённая конфигурация адаптера указывает PEFT 0.20.0. В журнале полного обучения указаны Transformers 5.15 и PEFT 0.20, две RTX A6000, BF16. Полной описи версий всех пакетов того GPU-окружения нет; основной CPU-набор зависимостей не выдаётся за его точную копию.

Перед полным обучением проверьте загрузку именно указанной ревизии Qwen3.6-35B-A3B и выполните короткий запуск `--smoke 2`. Исторический обучающий скрипт выбирает языковую часть модели и замораживает экспертные веса; поддержка этой архитектуры необходима в установленной версии Transformers. GPU-обучение и инференс большого разметчика при сборке выпуска повторно не выполнялись.
