# Онлайн-разметка префикса завышает счёт событий почти втрое, и задержка приёма этого не лечит

Дата: 2026-08-17. Источник: перемер калибровки в задании
docs/session_prompts/2026_08_16/01_structured_terminator чернового рабочего
репозитория, дополнение от 18:55 МСК; числа лежат там же в
internal_signals_poc/structured_terminator_2026_08_16/outputs/calib_online.json.
Перемер выполнен починенным клиентом разметчика после того, как эксперимент
дозового управления нашёл дефект прибора: у клиента не был выключен режим
размышления, и обрезанные ответы молча терялись.

## Вывод

Разметка недописанной трассы завышает число событий по сравнению с разметкой
той же трассы целиком в 2.87 раза. Прежняя оценка завышения 1.23 была снята
испорченным прибором и отозвана.

Задержка приёма — правило «считать событие только после того, как за точкой
дописано N сегментов» — завышение не уменьшает, а увеличивает: 2.89 при
задержке 1, 2.94 при 2, 3.02 при 3, 3.13 при 4, 3.25 при 5. Для живого контура
выбрана задержка 0 как наименьшее зло.

## Механизм

Разметчик читает префикс как законченное рассуждение. Обрыв на полуслове
выглядит для него как завершение мысли, и он ставит события завершения там, где
модель ещё продолжает работу. С ростом задержки приёма префикс длиннее, но
каждое промежуточное состояние всё равно размечается как законченное — ошибка
накапливается, а не вымывается. Согласуется с более ранней находкой линии шума
судьи: обрыв трассы удваивает частоту события консолидации у судьи по API, и там
завышение онлайн-счёта составляло 1.43.

## Следствия

1. Любой живой контур, считающий события по недописанной трассе — триггеры,
   награды, расписания вмешательств — обязан калибровать счёт делением примерно
   на три, либо пользоваться величинами, устойчивыми к обрыву.
2. Событийные величины, снятые на ходу, нельзя сравнивать со снятыми по готовой
   трассе без этой поправки: это разные измерения.
3. Задержка приёма как способ борьбы с завышением не работает и из
   инструментария исключается.

## Границы вывода

Число 2.87 измерено для ученика LoRA, на трассах gpt-oss-20b
в контуре структурного терминатора, при бюджетах 350 и 700 токенов, взятых от
медианы. Для судьи по API на другом корпусе ранее измерялось 1.43: масштаб
завышения зависит от разметчика и корпуса, но направление и бесполезность
задержки воспроизводятся.
