# Класс: оснастка

Здесь не проверяют гипотезу. Здесь чинят инструменты и собирают корпуса, которыми
потом пользуются остальные классы. Линия оснастки тоже получает предрегистрацию
и происхождение: сбой оснастки способен изобразить научный результат.

Что относится к классу:

- раннеры трасс, то есть программы, гоняющие модель по спискам вопросов;
- самохостные движки вывода и их настройка;
- поисковый цикл с локальной копией энциклопедии;
- сборка и вливание корпусов, разбор отказов;
- бенчмарки и их канонические срезы.

Перенесено:

  раннера, собран поисковый корпус на 2000 трасс, тело корпуса лежит в объектном
  хранилище.

Очередь на перенос:

- internal_signals_poc: retrieval_runs_2026_08_15,

- data/reasonops_benchmarks: описи бенчмарков, но не их
  тела.
