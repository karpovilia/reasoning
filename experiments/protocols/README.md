# Замороженные каноны

Канон — решение, принятое один раз и обязательное для всех линий работы. Канон
не переспоривают внутри отдельной линии: если он мешает, его меняют здесь,
отдельной датированной записью, и меняют для всех сразу.

Смысл канона в сопоставимости. Две линии работы, померившие качество на разных
выборках вопросов или разными пределами бюджета, несравнимы, и разность их чисел
ничего не значит.

- experiments/protocols/judge_question_pool.md — какие вопросы участвуют в
  подтверждающих замерах и как записывают неполное покрытие.
- experiments/protocols/shared_eval.md — общий протокол оценки управления
  бюджетом: разбиение, счёт бюджета, способ остановки, правило приёмки.
- experiments/protocols/budget_grid.md — из чего строят сетку пределов бюджета.

## Как менять канон

1. Дописать в файл канона датированный раздел с новой редакцией и причиной.
2. Не трогать прежнюю редакцию: числа, посчитанные по ней, остаются
   истолкованными по ней.
3. Указать, какие уже посчитанные числа новая редакция делает несравнимыми со
   свежими.
