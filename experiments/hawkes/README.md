# Класс: процессы с самовозбуждением

Процесс с самовозбуждением — модель потока событий, в которой прошедшее событие
поднимает вероятность последующих. Здесь проверяют, описывает ли такая модель
поток событий рассуждения, и что из неё следует.

Что относится к классу:

- матрицы влияния между типами событий;
- утверждения о поведении процесса и их проверка на материале;
- нейросетевые модели потока событий и их потолок качества;
- разбиение потока на циклы, то есть на кластеры событий, замыкаемые
  консолидацией;
- модели момента остановки.
