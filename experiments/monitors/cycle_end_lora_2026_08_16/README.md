# Прогнозист конца цикла на адаптере LoRA

Линия работы заведена 16 августа 2026 года. Класс — прогноз остатка: работа
отвечает на вопрос, сколько модели осталось размышлять, и ничего в ход
размышления не вмешивает.

## Что здесь измеряли

Цикл — кластер событий рассуждения, замыкаемый консолидацией, то есть событием,
которым модель закрывает найденное решение. Конец текущего цикла в момент t —
ближайшая консолидация строго после t, а если консолидаций после t больше нет,
то конец рассуждения. Остаток цикла — расстояние в токенах от t до этого конца.

Измеряли, умеет ли большая модель, дообученная низкоранговым адаптером LoRA,
прогнозировать этот остаток лучше простых бейзлайнов. Низкоранговый адаптер —
небольшая пара матриц, добавляемая к весам готовой модели; обучается только она,
сама модель остаётся неизменной.

Два плеча отличаются ровно одним решением: подан ли прогнозисту на вход
хоуковский блок. Это приписка в конце запроса, текстом: матрица возбуждения между
шестью типами событий размера 6 на 6, ветвящееся число, фоновые и текущие
интенсивности по типам. Плечо lora_noinj обучалось без этой приписки, плечо
lora_inj — с ней. Проверялось, помогает ли готовое знание о динамике переходов
между типами событий, поданное отдельным входом.

## Итог

Обученный адаптер побил все бейзлайны, и лучшим оказалось плечо без
хоуковского блока на входе.

| Что | Ранговая корреляция прогноза с фактом | Площадь под кривой ошибок для попадания конца цикла в горизонт 256 токенов |

| адаптер без хоуковского блока | 0.748 | 0.870 |
| адаптер с хоуковским блоком | 0.716 | 0.854 |
| градиентный бустинг на событийных признаках | 0.673 | 0.834 |

Числа лежат в
experiments/monitors/cycle_end_lora_2026_08_16/outputs/final_metrics.json,
замер без адаптера — в
experiments/monitors/cycle_end_lora_2026_08_16/outputs/zeroshot_metrics.json.
Оценка на 1500 окнах, 1156 трассах.

Отдельно измерен потолок согласия разметчика с самим собой: три независимых
прохода разметки по 130 трассам дают ранговую корреляцию остатка 0.875 и площадь
под кривой 0.919, файл
experiments/monitors/cycle_end_lora_2026_08_16/outputs/stage0_noise.json.
Это верхняя граница того, чего вообще можно достичь на такой разметке, и прогноз
0.748 читается против неё, а не против единицы.

Построчные прогнозы обоих плеч, прогнозы нулевого замера и список окон оценки в
git не хранятся: они содержат идентификаторы вопросов закрытых бенчмарков GPQA и
hle, а репозиторий уходит на GitHub. Они лежат в объектном хранилище, объект
gpb-reasoning/clean/outputs/outputs_cycle_end_lora_2026_08_16.tar.zst, манифест
data/manifests/outputs_cycle_end_lora_2026_08_16.json,
скачиваются командой make fetch. Это файлы eval_slice_uids.json, pred_inj.jsonl,
pred_noinj.jsonl и pred_zeroshot.jsonl.

Веса адаптеров в репозиторий не кладут, в
experiments/monitors/cycle_end_lora_2026_08_16/adapters
лежат только их описания adapter_config_noinj.json и adapter_config_inj.json.
Сами веса: user@192.168.2.43:/home/user/ki_cycle_end/outputs/lora_noinj и
user@192.168.2.43:/home/user/ki_cycle_end/outputs/lora_inj.
