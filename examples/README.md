# Синтетические примеры

Все тексты и значения в этом каталоге придуманы для демонстрации интерфейса. Здесь нет вопросов или трасс экспериментальных бенчмарков.

- `detector_segments.jsonl` — текстовые сегменты для детектора.
- `gate_observation.jsonl` — признаки префикса для гейта; `gate_expected.json` — результат исходного замороженного пакета на этом примере.
- `pipeline.jsonl` — завершённые текстовые сегменты с иллюстративными координатами. Координаты не получены реальной токенизацией.
- `trace.jsonl`, `annotation.jsonl` — пример связи трассы и отдельного слоя разметки. Вымышленные метки не являются человеческим эталоном.
